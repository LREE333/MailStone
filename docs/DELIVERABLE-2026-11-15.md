## 二、GitHub 首页会展示什么

### A. 可运行的原型（直接打开浏览器演示）

用 VS Code Live Server 打开 `index.html`，通过 URL 参数直接进入演示状态：

| 演示 | URL | 展示什么 |
|---|---|---|
| 1. 标准延期 | `?qa=extension-pre` | 问答流程 → GAR 9.6.1 政策检查 → 草稿 → lint 检查 |
| 2. 过期延期 | `?qa=extension-post` | 路线关闭 → 派生规则（suggest 级别）→ SEN 支援服务面板 |
| 3. TPG 范围外 | `?qa=extension-tpg` | 五级范围模型 → withhold → 指向未收集的 TPG 法规 |
| 4. 考试缺席 | `?qa=exam-ug` | 无中央规则 → 文档化 gap → SEN 路由（含"已确认"和"未确定"行） |
| 5. 成绩复议 | `?qa=grade` | 9.2.1 → 9.2.2/9.2.3 → 14 工作日 → 事前联系标记 |
| 6. 课程编号暂未知 | `?qa=extension-no-code` | 选择"暂未知" → 草稿保留可见的 `[Course code]` 待填栏位 |
| 7. 未确定主题 | `?qa=unsure` | `by_design` 空状态：不猜测任何程序 |
| 8. 语言切换 | `?qa=extension-pre&lang=zh-Hant`（或 `zh-Hans`） | 繁体／简体界面；<mark>草稿与政策原文仍为英文</mark> |

右上角也可直接点 EN / 繁 / 简 切换，无需改 URL；`?lang=` 可与任何 `?qa=` 组合。

**最新本地演示链路（浏览器复验进行中）：** 先选课程类型 → 再选请求 → 涉及时间的请求立即进入日期步骤（明确的年／月／日原生列表选择器；可明确保留未决定）→ 输入课程编号和老师姓名 → 从本地 LML 快照明确选择候选邮箱，或手动输入／暂未知 → 选择与老师关系并回答后续问题 → 看到<mark>政策条款原文引用</mark> → 生成草稿（含问候、适用时的自我介绍、结语）→ 查看<mark>彩色边签面板</mark>（Route / Fact Lock / Why this structure?；一次只开一个，关闭按钮／Escape 可关闭）→ 点击"Check this draft" → lint、SEN 支援信息及发送前检查表。Fact Lock 显示已提供的课程编号、姓名、邮箱及期望日期，不代表官方核实或已批准；修改相关输入会使旧收件人确认失效。Pebble → Display 可切换深色模式。

### 第三迭代补充（15 Nov 晚）

9. **合并重复的「何时」问题** — 原来学生先填日期，之后又会被问「截止日期过了吗」。现在取消后一个问题：第一个日期本身就能判断路线（已过 → 路线关闭；今天或以后 → 路线仍开；暂不确定 → 保持未定）。预设演示状态若没有日期，仍保留原有的时间判断。
10. **默认字号更易读** — 根字号由 16px 改为 17px，原先 0.68–0.78rem 的正文统一提到 0.9rem（约 15.3px）。在 Chrome 实测：自我检查文字 15.3px，页脚单行 53px，整页不溢出，只有主区域与草稿框内部滚动。
11. **页脚重做** — 两句话合成一条页脚：小石头标记 + 标语 + 带边框的「非官方服务」说明。两句原文不变，三语词典照常生效；另加深色与高对比度样式。
12. **复制行为写清楚** — 草稿是文本框，文字本来就可以直接选取复制。页面现在如实说明这一点，并指出「复制草稿」按钮会额外先跑自我检查与事实锁定。没有禁止选取，因为那会破坏读屏软件、放大镜和纯键盘操作。
