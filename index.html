    Hi, I'm Pebble. Ask me, or tell me what went wrong.
    What is MailStone?

    A guided tool that helps you work out which academic rule applies, who to write to, and what to say. It prepares a draft — it never sends anything.

    Why does it ask so many questions?

    EdUHK publishes different regulations for different programmes, and different situations need different letters. Answering one short question at a time stops the tool from quoting the wrong rule.

    Is my answer saved anywhere?

    No. There is no sign-in and no storage. Your answers live only in this browser tab and disappear when you close it.

    Why is the email always in English?

    The email is the thing being evaluated, and policy quotes must stay word-for-word. Only the interface is translated into 繁 / 简.

    Can I trust the policy quotes?

    Every quote is tied to a clause number, an official source URL and a retrieval date. If no rule is collected, MailStone says so instead of guessing.

    I don't know my course code or teacher's name.

    Choose "Not known yet". We can show possible contacts from course history when available. You can continue without an address; we never invent one.

    Your feedback is sent directly to the MailStone team so we can improve the tool. If the server is unavailable, your note is copied to the clipboard instead so it is never lost.
